## Introduction to Machine Learning
​Machine Learning (ML) is a subset of artificial intelligence (AI) focused on building systems that learn from data to improve performance on specific tasks without being explicitly programmed for every rule.

## Core Learning Paradigms
​Machine Learning is generally categorized into four main types based on how the model learns:
-​1. Supervised Learning
​The model learns from labeled training data. It tries to map inputs to known outputs.
​Regression: Predicting continuous values (e.g., house prices).
​Classification: Predicting categorical labels (e.g., spam detection).
